# LevelUpDiag Kristal v0.4 — Reference Adapter Execution

v0.4 moves K15 and K24 from adapter-readiness checks to executable external conformance tests.

The expected sibling repository is `../kristal-reference`. K15 executes Exchange identity/verification, Exchange relation invariants, deterministic RP-001 build/verification, and RP-006 tamper rejection. K24 generates ephemeral Ed25519 fixtures independently and tests valid signature/trust behavior plus wrong-key, tampered-message, revoked-key and expired-key rejection.

Passing K15 is scoped to the currently executable core vector surfaces. It does not turn RP-2..RP-5 into byte-format conformance claims; those require additional pinned profiles/fixtures.
